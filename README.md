# Browser Tetris

A browser-based Tetris project with a classic baseline and planned gameplay, configuration, leaderboard, and portable-save enhancements. No game implementation is available yet.

See the [project brief](docs/dev/PROJECT.md) for the proposed scope and the [preparation record](docs/dev/DOCS_PREPARATION.md) for its current review status.

Development uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md).
